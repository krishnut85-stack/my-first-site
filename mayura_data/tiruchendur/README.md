# 🌊 Tiruchendur — quality + value

*"The steady shore."* Buys **strong, durable, fairly-priced** businesses and
holds them patiently. Less about timing, more about quality.

## Trendlyne screen to build → save export here as `universe.csv`
Easy Mode filters (Fundamentals tab):
- **DVM → high Durability** (e.g. Durability score > 55)
- **DVM → high Valuation** (good value, e.g. Valuation score > 50)
- **ROE / ROCE > 15%** and **EPS Growth Qtr % > 0**
- **PEG / PE reasonable** (not overheated)
- (optional) **Return vs Nifty500 (1Y) > 0**

Columns to include: **NSE Code, Durability, Valuation, Momentum, Trendlyne
Checklist Score, PE TTM, Price to Book TTM** (Day SMA50/200 optional).

## Exit personality (patient)
−12% stop · trail armed +15% / 12% giveback · NO failed-breakout exit ·
45-day time stop. Edit in `mayura.py` → STRATEGIES["tiruchendur"].
