# EXTERNAL SOURCES MISSING - what a top Indian F&O desk reads that GIR does not (yet), with how to collect each (19 Nov 2026)

The trader, 19 Nov: "Is that only it? Or still many things are missing? Did you ask the desk about all these things? They know
many things which we did not cover. Please ask them because I don't want to waste time."

So the desk was asked again, this time only about **outside sources** (MISSING_KNOWLEDGE.md covers what the desk *knows*; this file
covers where the news and numbers *come from*). Four desk seats answered: world macro / geopolitics, Indian government and policy,
market flows and positioning, and alternative data. Their four lists are merged below, repeats removed, ranked by money made or
saved for an intraday F&O option buyer, most first.

**Left out because the plan already has them (BUILD_PLAN 1.2):** NSE / BSE corporate filings (F15), EOD deals / FII-DII /
participant OI (F13), Reuters / ET / Moneycontrol / CNBC sitemaps and live blogs (F16), TV speech-to-text (F17), Telegram (F18),
X lists (F19, off), SEBI / RBI / IRDAI / CERC / TRAI / CCI / DGFT / PIB / sansad / e-Gazette watchers (F20), ForexFactory
calendar (F22), Yahoo / LME / China world drivers (F23), VAHAN / Grid-India / IEX / CEA coal / DGCA / AMFI / fuel prices (F24).
Rows below that touch those feeds say what is *added*.

**Labels:** [V] = checked on the web by the desk on 19 Nov 2026. [M] = dated example from memory, confirm before quoting.
[E] = estimate. Times are IST. Effort: **S** = under a day, **M** = 1-3 days, **L** = a week or more.
Build day: **before Monday** = before the Mon 23 Nov session (Nov expiry day); **week 1** = 23-28 Nov; **later** = after that.
**Paid** rows need the trader's yes before anything is bought (standing rule).
