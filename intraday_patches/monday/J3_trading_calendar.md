# J3 - ONE TRADING CALENDAR for the prediction jobs - proof

Calendar: `v2/predict/common.py` `job_plan(day)` from NSE's holiday list (`/home/globalbot/intraday/holidays_2026.json`, source 'nse':
2026-10-02, 10-20, 11-08, 11-10, **11-24**, 12-25). Rules: 19:45 N19 (and 22:45 C22) on a trading day for the next session, and on a
Saturday / Sunday whose next day is a session (the Sunday 19:45 for Monday); a mid-week holiday runs nothing (Mon 23 Nov 19:45 already
predicts Wed 25). 07:15 U07, 09:09:30 P09 (the 09:08 version, run when NSE's final 09:08 pre-open snapshot is in), 09:05-15:36 LIVE,
15:50 SCORE: trading days only. Every job re-checks the calendar itself and logs 'not due today' if started on a wrong day.

Timers carry EXPLICIT dates (`v2/predict/caltimers.py`, rewritten nightly 23:50 IST by gir-v2predict-cal.timer for the next 21 days),
so `systemctl list-timers` shows the real next run and a holiday simply has no entry. All on Asia/Kolkata.
